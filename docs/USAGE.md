# 日常使用

按「你现在想干什么」组织。所有命令在仓库根目录执行。

## 1. 接一门新课

```
courses/<课程编号>/
  学生讲义.md      ← 学生端唯一能看到的材料
  资料清单.md      ← 材料别名与页码对照（可选）
  待确认与勘误.md   ← 已知错误，会自动进知识包（可选）
```

1. 建目录，编号用小写英文 + 连字符，例如 `linear-algebra-2026f`。
2. 讲义按 `## 小节` 分节；例题用 `**例 X.Y-N**` 开头——这两条决定了助教能不能精确定位。
3. 在 `config/courses.json` 的 `courses` 里加一条，`chapters[].sources` 指向你的讲义。
4. `npm run build && npm run build:vectors`。
5. 后台「＋ 新增学生」，选这门课，发码。

**讲义写法直接决定答疑质量**：

| 写法 | 效果 |
| --- | --- |
| `## 1.4 线性相关与线性无关` | 每一节成为可引用块，学生能点开看原文 |
| `**例 1.4-1**　设……` | 每道例题独立成块，助教能精确指到题 |
| 大段无小节的连续文字 | 会被切成大块，检索精度下降 |

## 2. 改讲义之后

```bash
npm run build          # 重建知识包
npm run build:vectors  # 重建向量（不建会自动退回纯词法，不会用错，但更弱）
npm run check          # 体检：有没有教师版混进学生端
```

## 3. 每天看后台

`http://127.0.0.1:8787/admin?token=...`

- **待处理**：学生问的但讲义里没有 → 这是你的讲义盲区，比任何主观判断都准
- **按类型**：讲知识占比高，说明概念部分没写清楚；只讲这一步多，说明学生卡在具体变形
- **没解决**：学生标了「没解决」的，优先看

## 4. 学生码管理

后台 → 学生与访问码：

| 操作 | 说明 |
| --- | --- |
| ＋ 新增学生 | 填名字、课程、额度，出码立刻生效（不用重启） |
| 换码 | 旧码立刻作废，历史问答与额度保留 |
| 停用 | 临时冻结，可恢复 |
| 删除 | 彻底移除，重启也不会复活；历史问答保留 |

命令行等价：

```bash
node scripts/add-student.mjs --name 张三 --course linear-algebra-demo --daily 10 --total 60
```

## 5. 学生画像

后台 → 学生与访问码 → 「画像」。文件在 `students/<学生目录>/学生画像.md`，也可以直接用 Obsidian 改。

- **自动摘要**（只读）：提问数、类型分布、章节分布、待补答、高频词、最近几问
- **生成草稿**：把摘要填进模板的「自动摘要（可删）」段，你挑有用的挪进上面的正文，然后删掉那一段
- **保存**：原子写入，旧版本备份到 `data/profile-backups/`

画像绑定的是 `students/<目录>`，新增学生时填「学生项目编号」即可（例如 `student-001`）。

建议每两周翻一次「教学中的问题」：重复出现两次以上的，直接变成讲义修改任务。

## 6. 额度

五个维度，`0` 表示不限：每天 / 每月 / 累计 / token / 每小时。

- 按次卖：设「累计」，比如 300
- 包月卖：设「每天」+「每月」
- 成本兜底：设「token」，比如 500000（约 ¥30 成本量级）

额度检查在调用模型之前，用完直接 429，不产生费用。

## 7. 命令速查

| 我想…… | 命令 |
| --- | --- |
| 起服务 | `npm start` 或 `./scripts/start.sh`（防休眠） |
| 停服务 | Ctrl+C，或 `pkill -f "node src/server.js"` |
| 改完讲义生效 | **存盘即可**（`npm run watch` 自动重建）；手动则 `npm run build` |
| 重建向量 | `npm run build:vectors`（加 `--only-stale` 只更新改过的章节） |
| 看检索质量 | `npm run eval` |
| 查黑名单泄漏 | `npm run check` |
| 跑自测（不花钱） | `npm test` |
| 发码 | `node scripts/add-student.mjs ...` |
| 看所有码 | `cat data/codes.md` |
| 看后台令牌 | `cat data/admin-token.txt` |
| 起隧道 | `./scripts/tunnel.sh` |
| 查隧道链接 | `./scripts/url.sh` |

## 8. 出问题怎么查

| 现象 | 先看 |
| --- | --- |
| 打不开 | 服务在不在：`curl -s localhost:8787/healthz` |
| 回答全是占位文字 | `.env` 没填 key 或没重启；`/healthz` 里 provider 应为 `deepseek` |
| 回答没有角标 | 模型没标块编号，状态会是「未定位」，后台能筛出来 |
| 讲义里没有的内容 | 正常，会回「无依据」并进待补答 |
| 额度用完太早 | 后台看每日设置；每小时默认 10 次 |
| 公式显示成 `$...$` | KaTeX 本地文件缺失，检查 `src/web/vendor/katex/` |
| 隧道 1033 / 连不上 | 关掉 TUN / 全局代理再试 |
