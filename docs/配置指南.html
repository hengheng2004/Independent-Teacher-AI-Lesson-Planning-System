独立教师 AI 工作台 · 配置指南

面向一对一 / 小班老师的自助系统：把课程材料变成知识库，让 AI 助教按你的讲法答疑，你在一个工作台里完成建课、备课、送审、看学情。

本文档同时提供 Markdown 与 HTML 两个版本，内容一致；HTML 版是单文件，可直接发给别人。

一、它解决什么问题

备课的痛点是资料散、重复劳动、没法复用；答疑的痛点是同一个问题讲十遍、半夜还得回。

这套系统把两件事接起来：

  • 课程材料只维护一份，多个学生共用
  • AI 助教只讲你讲义里的内容，每句话带出处，讲义没有的它说"不知道"
  • 备课的时候直接在工作台里和 AI 对话，产出直接落成讲义文件
  • 学生在手机上提问，你用同一个界面看他们卡在哪

它不是：通用聊天机器人、论文写作工具、在线课程平台。

二、七个核心特色

1. 课程库 × 学生库，多对多

接单不是"给学生建一门课"，而是三张表：

courses/<课程编号>/     课程库：材料、讲义、质检报告，可反复复用
students/<目录>/        学生库：一人一份画像
enrollments             报名关系：学生 × 课程

所以：同一个学生可以同时读数分和线代，一个访问码管所有课；同一门课教第二个学生时，直接"加课"，材料不重做。

2. 材料上传即生效

网页上把文件拖进来，系统自动重建知识包并为改动的章节重算向量（约 0.3 秒），学生下一次提问就能用上新内容。不需要记命令、不需要重启。

3. 五种讲法，按学生意图切换

不是所有问题都该用同一种答法：

学生问助教怎么答
什么是向量空间 / 为什么要求封闭讲知识：概念、条件、反例，不主动解题
这道题怎么做 / 直接贴题讲题·引导：点考点、给第一步、反问，不给答案
给我完整过程讲题·完整：分步推导，每步标依据，最后给检验
这一步怎么来的只讲这一步：只解释卡住的那一下，180 字内
这门课怎么复习 / 和后面什么联系延伸拓展：讲义部分照常引用，延伸部分必须标「拓展（不在讲义原文）」

判断用规则优先（免费、可解释），拿不准才让模型判一次。答完学生可以一键换讲法。

4. 回答必须带出处，编造的作废

模型只能引用本次喂给它的讲义块，编号形如 [[ch1-S7]]。服务端会逐条比对块编号：编出来的编号直接删掉；一条有效引用都没有的回答标记为「未定位」，进老师待办。

学生点角标能看到讲义原文，自己就能核对。

5. 本地向量检索，数据不出机器

  • 知识包：按小节和例题切块，标题与正文一起入库
  • 检索：词法（中文二元组）+ 向量（本地 bge-small-zh，512 维，23MB，离线推理）用 RRF 融合
  • 模型：只把「讲义摘录 + 这一条提问」发给厂商，不发学生姓名和历史

没有向量库服务要装，没有 embedding API 要付费。

6. 备课也用检索，不是硬塞全文

备课对话每轮会自动按你的提问从课程材料里挑相关段落（标题命中加权，无关不硬凑），再连同你勾选的文件一起给模型。所以：

  • 50 页的课件不需要整份塞进上下文
  • 你在对话里说「第 30 页」，检索会优先给同页内容
  • 扫描版 PDF 转成文字后同样参与检索
  • 回答里会写清「依据哪份材料、哪几页」，材料里没有的它标「未核对」

扫描版 PDF 怎么取字（可选两条路，都不强制全量）：

方式适合代价
本机 OCR（默认）macOS 自带 Vision，离线；其它系统装 poppler-utils + tesseract免费，50 页约十几秒
多模态模型没有本机 OCR、或需要更准的公式与表格按页计费，约每页几厘

配多模态模型做 OCR 的完整步骤见 视觉模型 OCR。

设置 OCR_BACKEND=auto|local|vision。不必一次识别整本：点「OCR 识别」时填 3-12 就只识别这几页，之后重跑别的页会合并进同一份文本，不会覆盖已有的。

7. 额度按单，成本可控

额度有五个维度（每天 / 每月 / 累计 / token / 每小时），0 表示不限。优先级：

全局默认  <  课程默认  <  学生  <  每单（学生×课程）

检查发生在调用模型之前，额度用完直接拒绝，不产生费用。实测一问约 ¥0.015。

三、界面预览

工作台概览：课程状态、待处理提问、按类型统计。

课程详情：材料上传后自动重建，标注每份材料是否进学生端。

备课页：左列文件树（勾选加入上下文）、中间对话（Markdown 与公式直接渲染）、右侧文件预览（可切源码）或待应用修改的 diff。

四、系统要求

项要求
Node.js≥ 22（用到内置 node:sqlite）
磁盘约 600 MB（依赖 471 MB + 模型 23 MB + 数据）
内存1 GB 以上
网络需要访问模型 API；本地向量推理不需要联网
可选cloudflared（临时公网）、npm

五、五分钟跑起来

git clone <仓库地址> teacher-ai && cd teacher-ai
npm install                  # 只有一个依赖：本地向量模型运行时
cp .env.example .env         # 不填 key 也能跑，会用 mock 模型（占位答案）

npm run build                # 讲义 → 知识包
npm run demo                 # 起服务

打开 http://127.0.0.1:8787/teacher，用后台令牌进入。

cat data/admin-token.txt     # 令牌

也可以直接带令牌：

http://127.0.0.1:8787/teacher?token=<令牌>

学生入口是 http://127.0.0.1:8787，输访问码即可提问（码在后台「学生」页生成）。

六、配置文件详解

6.1 .env

复制 .env.example 后填写。这个文件永不进版本库。

变量默认说明
LLM_PROVIDERautodeepseek / openai / mock / auto（有 key 用 deepseek，没有用 mock）
DEEPSEEK_API_KEY空DeepSeek 的 key，https://platform.deepseek.com/api_keys
DEEPSEEK_MODELdeepseek-chat模型名
OPENAI_BASE_URL空任意 OpenAI 兼容端点，填了就走这一路
OPENAI_API_KEY空上面的 key
OPENAI_MODELgpt-4o-mini模型名
PORT8787服务端口
ADMIN_TOKEN空教师令牌；留空则自动生成到 data/admin-token.txt
RATE_LIMIT_PER_HOUR10每小时防连刷默认值（可被课程/学生覆盖）
OCR_BACKENDauto扫描版 PDF 取字方式：local 本机 OCR / vision 多模态模型

换厂商只改三行，不用动代码：

LLM_PROVIDER=openai
OPENAI_BASE_URL=https://dashscope.aliyuncs.com/compatible-mode/v1
OPENAI_API_KEY=sk-xxx
OPENAI_MODEL=qwen-plus

换完一定要真问一题，确认引用正常。弱模型常常不肯输出 [[块编号]]，那样所有回答都会变成「未定位」。

6.2 config/courses.json

课程库的唯一真相。一个课程一条：

{
  "quotaDefaults": { "daily": 20, "monthly": 200, "total": 0, "tokens": 0, "burstPerHour": 10 },
  "courses": [
    {
      "id": "linear-algebra-2026f",
      "name": "线性代数",
      "school": "示例大学",
      "teacher": "张老师",
      "enabled": true,
      "quota": { "daily": 20, "monthly": 200 },
      "policy": { "defaultMode": "hint", "allowFullSolution": true },
      "denyGlobs": ["*备课*", "*教师*", "*答案*", "*解答*", "资料/*"],
      "chapters": [
        { "key": "ch1", "title": "第一章 向量空间", "sources": ["学生讲义.md"] }
      ],
      "references": ["资料清单.md"],
      "errata": ["待确认与勘误.md"],
      "notes": []
    }
  ]
}
字段作用
id同时是目录名：courses/<id>/，只能用 2–41 位小写字母、数字、连字符
chapters[].sources这一章进知识包的文件（相对课程目录）。不在 sources 里的文件不会被检索
denyGlobs黑名单，命中的文件在构建期就被拒绝。带 / 的匹配相对路径，不带 / 的只匹配文件名
references / errata资料清单（页码对照）与勘误，会随每次回答一起进上下文
quota这门课的默认额度，被学生或每单覆盖

白名单机制是这套系统的安全底线：教师版讲义、答案 PDF 只要命中黑名单，就根本不进学生端知识包——不是靠提示词约束，是物理排除。

6.3 目录结构

config/courses.json     课程库配置
courses/<id>/           课程材料（学生讲义、资料清单、勘误）
courses/<id>/备课/       AI 生成的讲义（教师版、学生版）
courses/<id>/质检/       审查报告
students/<目录>/         学生画像.md（老师手写）
agents/                 备课 / 审查 agent 的角色定义，可改
data/                   SQLite、令牌、码表、模型、各类备份（不进版本库）
packs/                  知识包与向量索引（可删可重建）

6.4 agent 角色（可改）

agents/prep-agent.md 和 agents/review-agent.md 是纯 Markdown，直接决定 AI 怎么写讲义、怎么写审查报告。想让它更严格、更啰嗦、换格式，改这两个文件即可，不用动代码。

七、打包与部署

两种交付形态，按对方的技术水平选。

7.1 绿色包（对方双击即用）

npm run pack
# → dist/独立教师AI工作台-<版本>-macOS-<arch>.zip（约 110 MB）

包里自带 Node 运行时、裁过的依赖、向量模型、示例课程、双击启动脚本。对方不需要装任何东西：解压 → 双击「启动.command」→ 自动建索引、起服务、开浏览器。

细节：

  • 依赖已裁掉其它平台二进制和浏览器版运行时（471 MB → 129 MB）
  • 首次启动自动生成 .env 与登录令牌，并建好知识包与向量（约 1–2 秒）
  • 端口被占用会自动往后找
  • 目前只出 macOS 包；Windows 需要另做一份（依赖里 win32 二进制已裁，要还原）

7.2 服务器部署（对方只收一个网址）

见 deploy/README.md，含 systemd 单元、Caddy/Nginx 配置、数据迁移与备份脚本。

关键两点：

  • .env 里 HOST=127.0.0.1，只让反代访问，不要开 0.0.0.0
  • 反代必须关掉响应缓冲，否则备课对话的流式输出会憋到最后一次性出现

八、三种典型部署

方案 A：本机 + 临时隧道（最快，适合试点）

./scripts/start.sh     # 起服务（同时拉起讲义监听）
./scripts/tunnel.sh    # 另开终端，拿公网链接

注意三件事：

  1. 开着 TUN / 全局代理时，Cloudflare 隧道连不上（它的 7844 端口会被虚拟网卡抢走），要先关掉
  2. 隧道窗口不能关，电脑合盖会断
  3. 每次重启链接都会变，码不变

方案 B：自己的 VPS（长期在线）

服务默认只监听 127.0.0.1，放到 VPS 上学生访问不到。两种做法：

  • 继续用隧道（最省事，cloudflared 也有 Linux 版）
  • 改监听地址 + Nginx 反代 + 域名
// src/server.js
server.listen(PORT, '0.0.0.0', ...)

再加个 systemd 单元让它常驻。start.sh 里的 caffeinate 是 macOS 独有的，Linux 上用不到。

方案 C：局域网

学生和你同一个 WiFi 时最稳：

ipconfig getifaddr en0        # macOS 取本机 IP
# 学生打开 http://10.x.x.x:8787

九、索引是何时更新的

一句话：改了什么就重建什么，粒度为"章"。 但不同动作的自动化程度不一样，这张表是准确的：

你做的操作索引会自动更新吗走什么
网页上传 .md / .txt✅ 立刻上传接口里直接重建（含向量）
网页上传扫描版 PDF❌ 只存档PDF 没有文字层，任何提取器都取不到
对 PDF 点「OCR 识别」✅ 识别完自动挂到该章并重建OCR 完成 → 写入 xxx.ocr.md → 挂进章节 sources → 重建
网页删除材料✅ 立刻删除接口里重建
工作台里「应用」AI 生成的文件✅ 立刻写入后重建
编辑课程（改章节 / 材料归属）✅ 保存后保存接口里重建
用编辑器直接改 courses/ 里的文件⚠️ 只有 watcher 在跑时npm run watch 或绿色包（启动时自带）
换向量模型✅ 下次建索引时模型名与讲义哈希一起校验，不一致就整章重算

重建的分寸

  • 知识包（切块）：每次全量重切，毫秒级，不心疼
  • 向量：按章比对 packVersion（该章所有源文件的 SHA-256），没变的章直接复用，只重算改过的章
  • 单章约 0.3 秒；没改动时重建耗时 1 毫秒

两级检索，各自更新

学生答疑备课对话
索引对象章节 sources 里的文件课程根目录所有可读文字（含 OCR）
检索方式词法 + 向量，RRF 融合词法 + 向量，RRF 融合
更新时机上面那张表（显式重建）每次提问时按文件 mtime 惰性刷新

所以给备课补材料不用点重建——下一次对话就生效；但要让学生也能检索到，必须挂进章节（这也是 OCR 完成后自动挂章节的原因）。

十一、学生怎么用

一句话：建号发码，学生打开网址输码就能问。 但"能进去"和"能答上"是两件事，发码前先对一遍下面四条。

9.1 你这边（两步）

学生 → 新增学生 → 填名字 + 选课程 + 设额度 → 屏幕显示一次访问码
把码发给学生（只显示一次，之后在 data/codes.md 里查）

建完立刻生效，不用重启。

一人可以报多门课，一个码管所有课，学生端顶部切换课程。

9.2 发码前的四条检查

前提怎么查缺了会怎样
课程有知识包课程页能打开、跑过 npm run build学生提问返回「知识包还没构建」
章节挂了材料课程 → 编辑课程，看每章下的材料标签是否点亮该章没内容，检索不到东西
配了模型 key.env 里的 DEEPSEEK_API_KEY，看 /healthz 的 provider能登录能用，但答案是「占位内容」
服务能被访问到见第七章部署方案学生那边打不开网页

最后一条最容易漏：服务默认只监听 127.0.0.1，同一 WiFi 的学生也打不开，必须走隧道或改监听地址。

9.3 学生看到什么

进门后是一页对话。每条回答带角标 [1] [2]，点角标能看到讲义原文那一段，可以自己核对。讲义里没有的内容，它会说"材料里没有"，而不是编。

9.4 可直接转发给学生的说明

【XX 课 AI 助教】

网址：https://xxxx.trycloudflare.com
你的访问码：ABCD-1234

怎么用：
1. 手机或电脑打开上面的网址
2. 输入访问码
3. 直接打字提问，比如"这道题第一步为什么设 k=1"、"什么是线性无关"

说明几点：
- 它只讲这门课讲义里的内容，回答都会标出处，点角标能看原文
- 讲义里没有的，它会直接说没有，不会瞎编——这类问题直接问我
- 每天最多问 XX 次，够用；用完找我加
- 换设备不用重新输码，网址也不变

9.5 常见问题

学生说先查
打不开网页隧道是否还开着（链接每次重启会变），或改用局域网地址
码无效后台看是否被停用；码是否被换过（data/codes.md 有全部现行码）
说"知识包还没构建"这门课还没建包，npm run build
说"材料里没有"正常行为；要它答得上，先补讲义、再让它重试
额度用完学生行「额度」，可单独调这一单的次数
想换课学生行「加课」，不用换码

十二、备份与迁移

必须备份（这些丢了就真丢了）：

不用备份（可重建）：packs/、node_modules/。

搬到新机器：

# 旧机器
pkill -f "node src/server.js"; pkill -f "scripts/watch.mjs"
rsync -av --exclude node_modules --exclude packs 独立教师AI管理系统/ 新机器:~/teacher-ai/

# 新机器
cd ~/teacher-ai
npm install
node scripts/build-packs.mjs && node scripts/build-vectors.mjs
node src/server.js

学生码不会失效：码的哈希在 config/students.json 和数据里，一起搬走就行。

现象先查

回答没有角标模型没按格式输出块编号，后台「未定位」能筛出来

十四、隐私与安全

  • 学生提问、画像、访问码只写本地磁盘；除模型厂商外不上传任何第三方
  • 发给模型的只有「讲义摘录 + 这一条提问」，不含学生姓名、历史对话
  • 访问码只存 SHA-256，明文只在你生成时显示一次
  • 教师令牌走 HttpOnly cookie，连续 5 次错误锁 60 秒
  • .gitignore 已排除 .env、data/、packs/

你仍需要自己把控：学生姓名属于个人信息，公开仓库或把项目发给别人之前，检查 students/、courses/、config/students.json 里有没有真实人名。
