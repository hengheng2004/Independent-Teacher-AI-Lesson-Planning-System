# 独立教师 AI 工作台 · 配置与使用指南

> 给一对一 / 小班老师的自助系统：把课程材料变成知识库，让 AI 助教按你的讲法答疑，你在一个界面里完成建课、备课、送审、看学情。
>
> 本文档同时提供 Markdown 与 HTML 两个版本，内容一致；HTML 是单文件，可直接发给别人。

---

## 一、它是什么

三个入口，一个进程：

| 入口 | 地址 | 谁用 |
| --- | --- | --- |
| 教师工作台 | `/teacher` | 你 |
| 学生答疑 | `/` | 学生，凭访问码 |
| 教师后台（旧） | `/admin` | 兼容用，功能已被工作台覆盖 |

数据全部存放在本机目录里，除调用模型 API 外不外发。

**它不是**：通用聊天机器人、在线课程平台、作业批改系统。

## 二、安装

### 2.1 系统要求

| 项 | 要求 |
| --- | --- |
| Node.js | ≥ 22（用到内置 `node:sqlite`） |
| 磁盘 | 约 1 GB（依赖 + 模型 + 数据） |
| 内存 | 1 GB 起 |
| 网络 | 需要访问模型 API；本地向量推理不联网 |

### 2.2 方式一：绿色包（最省事）

拿到 `独立教师AI工作台-<版本>-macOS-arm64.zip`（或 Windows 版）后：

1. 解压到任意目录（**不要放在含中文或空格的路径下**，先别放桌面）
2. macOS 双击 `启动.command`；Windows 双击 `启动.bat`
3. 首次启动会自动：生成 `.env`、建知识包与向量、挑一个空闲端口、打开浏览器

包里自带 Node 运行时、依赖、向量模型和示例课程，**对方不需要装任何东西**。

### 2.3 方式二：从源码运行

```bash
git clone <仓库地址> teacher-ai && cd teacher-ai
npm install                 # 只有一个运行时依赖（本地向量模型运行时）
cp .env.example .env        # 不填 key 也能跑，会用 mock 模型（占位答案）
npm run build               # 讲义 → 知识包
npm run build:vectors       # 生成向量（需要 data/models 里的模型文件）
npm start                   # 默认 8787
```

打开 `http://127.0.0.1:8787/teacher`，令牌在 `data/admin-token.txt`。

### 2.4 方式三：装到服务器

见 [`deploy/README.md`](../deploy/README.md)，含 systemd 单元、Caddy/Nginx 配置、数据迁移与备份脚本。

两个要点：

- `.env` 里 `HOST=127.0.0.1`，只让反代访问，别开 `0.0.0.0`
- 反代必须关响应缓冲（`flush_interval -1` / `proxy_buffering off`），否则备课对话的流式输出会憋到最后一次性出现

## 三、配置

### 3.1 两处配置，优先级明确

| 位置 | 改什么 | 生效方式 |
| --- | --- | --- |
| 工作台「设置」页 → `data/settings.json` | 三套模型、API key、OCR 方式 | 保存即生效，不用重启 |
| `.env` | 端口、监听地址、默认模型、额度默认值 | 改完重启服务 |

优先级：**`data/settings.json` > `.env` > 内置默认**。

`settings.json` 里的 key 明文存储（权限 0600，已 gitignore），界面上只回显后四位。

### 3.2 `.env` 全部变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `LLM_PROVIDER` | `auto` | `deepseek` / `openai` / `mock` / `auto` |
| `DEEPSEEK_API_KEY` | 空 | DeepSeek 的 key |
| `DEEPSEEK_MODEL` | `deepseek-chat` | 模型名 |
| `OPENAI_BASE_URL` | 空 | 任意 OpenAI 兼容端点 |
| `OPENAI_API_KEY` | 空 | 上面的 key |
| `OPENAI_MODEL` | `gpt-4o-mini` | 模型名 |
| `PORT` | `8787` | 端口（绿色包会自动挑空闲端口） |
| `HOST` | `127.0.0.1` | 监听地址；只有要给局域网用时才改 `0.0.0.0` |
| `ADMIN_TOKEN` | 空 | 教师令牌；留空则自动生成到 `data/admin-token.txt` |
| `RATE_LIMIT_PER_HOUR` | `10` | 每小时防连刷默认值 |
| `OCR_BACKEND` | `auto` | `auto` / `local` / `vision` / `command` |
| `OCR_BASE_URL` | 空 | 视觉模型端点（OpenAI 兼容） |
| `OCR_API_KEY` | 空 | 视觉模型的 key |
| `OCR_MODEL` | 空 | 视觉模型名 |
| `OCR_COMMAND` | 空 | 自带 OCR 的命令模板，见 5.4 |
| `PREP_MAX_TOKENS` | `32000` | 备课单次输出上限 |
| `REVIEW_MAX_TOKENS` | `6000` | 审查单次输出上限 |

### 3.3 设置页能改什么

| 分组 | 字段 |
| --- | --- |
| 备课 / 答疑（聊天模型） | 厂商、Base URL、模型名、API Key |
| 审查 agent | 模型名（留空跟随聊天模型） |
| OCR 方式 | 自动 / 本机 OCR / 视觉模型 / 自定义命令（标出各自是否可用） |
| OCR 视觉模型 | Base URL、模型名、API Key、自定义命令 |

配完可以点 **「测试聊天」** 和 **「测试 OCR」**：前者真发一句话，后者生成一张带文字的小图让视觉模型识别，两边都会把服务端原话回显出来。**先测通再拿它去跑几十页 PDF。**

### 3.4 `config/courses.json`

课程库的唯一真相，一个课程一条：

```json
{
  "quotaDefaults": { "daily": 20, "monthly": 200, "total": 0, "tokens": 0, "burstPerHour": 10 },
  "courses": [
    {
      "id": "linear-algebra-2026f",
      "name": "线性代数",
      "school": "示例大学",
      "teacher": "张老师",
      "enabled": true,
      "quota": { "daily": 20, "monthly": 200 },
      "policy": { "defaultMode": "hint", "allowFullSolution": true },
      "denyGlobs": ["*备课*", "*教师*", "*答案*", "*解答*", "资料/参考书/*"],
      "chapters": [
        { "key": "ch1", "title": "第一章 向量空间", "sources": ["学生讲义.md"] }
      ],
      "references": ["资料清单.md"],
      "errata": ["待确认与勘误.md"],
      "notes": []
    }
  ]
}
```

| 字段 | 作用 |
| --- | --- |
| `id` | 同时是目录名 `courses/<id>/`，允许大小写字母、数字、`-`、`_` |
| `chapters[].sources` | 这一章进知识包的文件（相对课程目录）。**不在 sources 里的文件不会被学生检索到** |
| `denyGlobs` | 黑名单，构建期就拒绝。带 `/` 的匹配相对路径，不带的只匹配文件名 |
| `references` / `errata` | 资料清单（页码对照）与勘误，随每次回答进上下文 |
| `quota` | 这门课的默认额度，可被学生或每单覆盖 |

**白名单是安全底线**：教师版讲义、答案 PDF 只要不在 `sources` 里，就根本不进学生端知识包——靠物理排除，不靠提示词约束。

### 3.5 目录结构

```
config/courses.json     课程库配置
config/students.json    学生种子（姓名 + 码哈希），运行时会变
courses/<id>/           课程材料（讲义、资料清单、勘误）
courses/<id>/备课/       AI 生成或你自己放的讲义
courses/<id>/质检/       审查报告
students/<目录>/         学生画像.md（你手写）
agents/                 备课 / 审查两个 agent 的角色定义，可改
data/                   SQLite、令牌、码表、向量模型、各类备份
data/settings.json      界面里保存的模型配置
packs/                  知识包与向量索引（可删可重建）
```

## 四、教师工作台怎么用

### 4.1 概览

近 7 天提问数、待处理数、按讲法分类、课程状态（未备课 / 备课中 / 需修订 / 可授课 / 阻塞）。

### 4.2 课程库

- **新建课程**：编号（目录名）+ 名称 + 学校/教师 + 章节
- **打开** 进课程详情：章节表、材料表、质检报告
- **编辑课程**：改名、增删章节、把材料勾进某一章
- **删除课程**：从列表移除，材料移到 `courses/_archived/`（不真删）
- **打开文件夹**：在 Finder 里打开课程目录

**上传材料**：整页都能拖（不用对准虚线框），也可以点击选择。`.md` / `.txt` 直接进检索；扫描版 PDF 点「OCR 识别」转文字后同样可检索。**单个文件最大 200MB**。

上传后自动重建索引，界面回报块数与耗时，不需要敲命令。

### 4.3 备课

三栏：左边文件树、中间对话、右边文件预览或 diff。

**勾选材料**（左列复选框）决定这次对话"必带"的上下文。除此之外，每轮还会**自动按你的提问从课程材料里检索相关段落**（标题命中加权、总预算 7000 字），所以 50 页课件不需要整份塞进去。

**输出上限**在输入框下方：

```
32000 tokens ≈ 最多 51,200 字
```

点它可调（1000–32000）。换算就是 `token × 1.6`。这只是上限，不写满不花钱。

> 推理型模型（`deepseek-flash`、`reasoner`、`r1` 等）会先把预算花在"思考"上，容易出现正文被截断。这种情况建议换成 `deepseek-chat`，或者把上限调大。

**AI 的输出不会直接写盘**。它给出带路径的代码块，服务端解析成 diff 显示在右侧，你点「应用」才落盘；写入前有 mtime 校验，冲突会拒绝并让你重新生成。

**送审**：把本章讲义和资料清单一起交给审查 agent，报告写到 `质检/`，结论变成课程状态徽章。

**打开文件夹 / 下载**：前者在你这台 Mac 上打开本章产物目录；后者把当前文件存到正在使用的设备（手机上也能存）。

### 4.4 学生库

| 操作 | 说明 |
| --- | --- |
| 新增学生 | 名字 + 课程（可暂不选）+ 额度；生成访问码，只显示一次 |
| 加课 | 把已有课程加给这个学生（一人可多课，一码通用） |
| 额度 | 按课程设置（每单可单独设次数） |
| 画像 | 自动摘要 + Markdown 编辑 |
| 换码 | 旧码立即失效，历史与额度保留 |
| 停用 / 启用 | 临时关闭，不动数据 |
| 删除 | 码失效、报名清除、**问答历史保留**、画像目录不删 |

### 4.5 问答

学生提问流水：时间、学生、讲法、问题、状态。`未定位`（回答没有有效引用）的排在最上面，这是补讲义的信号。

### 4.6 设置

见 3.3。页面底部会显示**代码版本**，两个实例版本不一致时能一眼看出来。

## 五、学生端与 OCR

### 5.1 学生怎么进来

打开 `http://你的地址:8787/` → 输入访问码 → 直接提问。一人多课时顶部会多一排课程切换。

不需要注册、不需要装 App、换设备不用重新输码。

### 5.2 五种讲法

| 学生问 | 助教怎么答 |
| --- | --- |
| 什么是向量空间 / 为什么要求封闭 | 讲知识：概念、条件、反例，不主动解题 |
| 这道题怎么做 / 直接贴题 | 讲题·引导：点考点、给第一步、反问，不给答案 |
| 给我完整过程 | 讲题·完整：分步推导，每步标依据，最后给检验 |
| 这一步怎么来的 | 只讲这一步：180 字内 |
| 这门课怎么复习 / 和后面什么联系 | 延伸拓展：讲义部分照常引用，延伸部分必须标「拓展（不在讲义原文）」 |

判断用规则优先（免费、可解释），拿不准才让模型判一次。答完学生可以一键换讲法。

### 5.3 三件保证质量的事

**引用可校验**：模型只能引用本次喂入的块，编号形如 `[[ch1-S7]]`。服务端逐条比对，编造的编号直接删掉；一条有效引用都没有的回答标记为「未定位」进你的待办。

**能追问**：每题都带最近两轮上下文。学生问"第四步那个公式为什么"，系统会把上一轮引用过的块补回上下文，不会回一句"找不到资料"。

**讲义外也答**：讲义里没有的内容，会明确标注「这个点讲义里没有直接写，下面的解答超出讲义范围」，并尽量沿用讲义的符号和术语，不编造页码题号。

### 5.4 扫描版 PDF 的 OCR

PDF 传上去只是存档，**不会进检索**——扫描件没有文字层。要让它可用，点「OCR 识别」。

四种方式（设置页里选，或 `.env` 的 `OCR_BACKEND`）：

| 方式 | 前提 | 特点 |
| --- | --- | --- |
| 自动 | — | 配了视觉模型就用它，否则用本机 |
| 本机 OCR | macOS（内置 Vision，随包附带预编译二进制） | 免费、快；公式和表格较弱 |
| 视觉模型 | `OCR_BASE_URL` + `OCR_MODEL` + `OCR_API_KEY` | 公式能出 LaTeX、表格保结构；按页计费 |
| 自定义命令 | 你的 OCR 能对一张图输出文字 | 见下 |

**不必全量**：OCR 时可以填页码范围（如 `3-12`），之后重跑别的页会合并进同一份 `.ocr.md`，不覆盖已识别的页。

**识别完会自动做三件事**：写 `<文件名>.ocr.md` → 按同名 PDF 找所属章节并挂进去 → 重建索引。所以 OCR 完学生就能搜到。

自定义命令的占位符：

```bash
OCR_COMMAND=python3 -m rapidocr_onnxruntime --img {img}
OCR_COMMAND=tesseract {img} stdout -l chi_sim+eng
```

可用 `{img}`（页面图片）、`{page}`、`{pdf}`、`{from}`、`{to}`。命令的 stdout 就是该页文字。

### 5.5 手机上

学生端是移动优先的：公式用 KaTeX 渲染，长公式/长矩阵在气泡内横向滚动，不会撑破布局。

如果公式显示成原始 `$...$`（组件没加载），页面顶部会提示「公式渲染组件没加载成功，请强制刷新」。

## 六、索引什么时候更新

**改了什么就重建什么，粒度为"章"。**

| 操作 | 自动更新 | 走什么 |
| --- | --- | --- |
| 网页上传 `.md` / `.txt` | ✅ 立刻 | 上传接口里重建 |
| 网页上传扫描版 PDF | ❌ 只存档 | 没有文字层 |
| 点「OCR 识别」 | ✅ 自动挂章节并重建 | OCR 完成后 |
| 删除材料 | ✅ 立刻 | 删除接口里重建 |
| 「应用」AI 生成的文件 | ✅ 立刻 | 写入后重建 |
| 编辑课程（章节 / 材料归属） | ✅ 保存后 | 保存接口里重建 |
| 用编辑器直接改文件 | ⚠️ 只有 watcher 在跑时 | `npm run watch` 或绿色包 |
| 换向量模型 | ✅ 下次建索引 | 模型名与哈希一起校验 |

知识包每次全量重切（毫秒级）；向量按章比对 `packVersion`（该章所有源文件的 SHA-256），没变的章直接复用，只重算改过的章（约 0.3 秒/章）。

### 7.1 备份

**必须备份**（丢了就真丢了）：

```
config/courses.json     课程配置
config/students.json    学生种子（姓名 + 码哈希）
courses/                你的材料与生成的讲义
students/               学生画像
data/assistant.db       问答记录、额度用量
data/settings.json      界面里的模型配置
.env                    模型 key 与端口
data/models/            向量模型（23MB，重下很麻烦）
```

**不用备份**（可重建）：`packs/`、`node_modules/`。

### 7.2 迁移到另一台机器

```bash
# 旧机器：停服务
pkill -f "node src/server.js"

# 拷贝（排除依赖与索引）
rsync -av --exclude node_modules --exclude packs 工作台/ 新机器:~/teacher-ai/

# 新机器
cd ~/teacher-ai
npm install
node scripts/build-packs.mjs && node scripts/build-vectors.mjs
node src/server.js
```

**学生码不会失效**：哈希在 `config/students.json` 和数据库里，一起搬就行。

### 7.3 开机自启（macOS）

新建 `~/Library/LaunchAgents/com.teacher.ai.plist`，用 `launchctl bootstrap gui/$(id -u) <plist>` 加载。注意加一个等待外接盘挂载的包装脚本，盘没插时不要让 launchd 疯狂重试。

## 八、故障排查

| 现象 | 先查 |
| --- | --- |
| 打不开 | `curl -s localhost:8787/healthz` |
| 回答是占位文字 | `.env` 没填 key，`/healthz` 里 provider 应为 `deepseek` |
| 报 `Model not exist` | 模型名写错，或该账号没开这个模型；点「测试聊天」看服务端原话 |
| 报 401 / `Incorrect API key` | key 不对，或填到了另一组（聊天和 OCR 是两把 key） |
| 备课"没反应" | 输出被截断：换 `deepseek-chat`，或把「输出上限」调大；界面会标「输出被截断」 |
| 回答没有角标 | 模型没按格式输出块编号，看「问答」页的「未定位」 |
| 上传了材料但没生效 | 看课程页是否显示已重建；文件是否 `.md` / `.txt` |
| PDF 传上去搜不到 | 扫描版没有文字层，点「OCR 识别」；可只识别用到的页 |
| 公式显示成 `$...$` | 强制刷新；仍不行看页面顶部提示 |
| 学生说码无效 | 后台看是否被停用；`data/codes.md` 查明文 |
| 端口被占用 | `lsof -ti :8787 \| xargs kill` |
| 隧道 1033 | 关掉 TUN / 全局代理再试 |
| 设置页显示旧内容 | 强制刷新；看设置页底部「代码版本」是否落后 |

## 九、隐私与边界

- 学生提问、画像、访问码只写本地磁盘；除模型厂商外不上传第三方
- 发给模型的只有「讲义摘录 + 这一条提问 + 最近两轮上下文」，不含学生姓名
- 访问码只存 SHA-256，明文只在你生成时显示一次
- 教师令牌走 HttpOnly cookie，连续 5 次错误锁 60 秒
- `.gitignore` 已排除 `.env`、`data/`、`packs/`、`students/`、真实课程

**打包或分享前**：`npm run pack` 会在压缩前自动安检，发现 `.env`、`data/settings.json`、`data/admin-token.txt`、`config/students.json` 或任何 `sk-` 形态的字符串就直接失败。

**你仍需自己把控**：学生姓名属于个人信息，公开仓库或把项目发给别人之前，检查 `students/`、`courses/` 里有没有真实人名。
